# SecureMemo

로컬 전용 암호화 메모 애플리케이션

## 주요 기능

- 🔒 **완전한 로컬 저장**: 모든 데이터는 로컬에만 저장되며 온라인 전송 없음
- 🔐 **AES-256-GCM 암호화**: 메모와 녹음 모두 사용자가 정한 비밀번호로 암호화
- 🗂 **비밀번호별 메모 공간**: 다른 비밀번호를 입력하면 별도의 새 메모 공간이 만들어짐
- 🎤 **음성 녹음**: 메모와 함께 음성 녹음 및 재생
- 🖍 **녹음-메모 연결**: 녹음 중 작성한 메모가 재생 시 해당 시점에 흰색 테두리로 표시
- 📄 **Word 내보내기**: 메모를 Word 문서로 내보내기
- 🔄 **자동 업데이트**: GitHub 릴리즈를 통한 자동 업데이트
- 🌙 **다크 테마**: 눈에 편안한 다크 모드 UI

## 다운로드

[최신 릴리즈 다운로드](https://github.com/grasion/SecureMemo/releases/latest)

### 설치 방법

1. **설치 파일 (권장)**
   - `SecureMemo-Setup-vX.X.X.exe` 다운로드
   - 실행하여 설치
   - 시작 메뉴 및 바탕화면 바로가기 생성

2. **포터블 버전**
   - `SecureMemo-Portable-vX.X.X.zip` 다운로드
   - 압축 해제 후 `SecureMemo.exe` 실행
   - 설치 없이 USB 등에서 실행 가능

## 시스템 요구사항

- Windows 10/11 (64-bit)
- .NET 10.0 Runtime (자동 포함)

## 사용 방법

### 기본 사용

1. 프로그램 실행
2. "새 노트" 버튼으로 메모 생성
3. 제목과 내용 입력 (자동 저장)
4. 메모 목록에서 선택하여 편집

### 비밀번호와 메모 공간

1. 실행하면 비밀번호를 입력합니다.
2. 처음 쓰는 비밀번호라면 한 번 더 입력해 **새 메모 공간**을 만듭니다.
3. 다른 비밀번호를 입력하면 그 비밀번호의 메모 공간이 열립니다 (서로의 메모는 보이지 않음).
4. 사이드바의 **잠그기**(Ctrl+L)로 잠그고 다른 비밀번호로 열 수 있습니다.

> ⚠ 비밀번호를 잊어버리면 저장한 메모는 복구할 방법이 없습니다.

### 음성 녹음 + 메모 연결

1. 메모 선택 후 🎤 녹음 버튼 클릭 (Ctrl+R)
2. 녹음하는 동안 본문에 메모 작성 — 입력한 내용이 녹음 시점과 자동으로 연결됨
3. 중지 버튼으로 녹음 종료
4. 하단 재생 바에서 ▶ 재생 — 그 시점에 작성한 메모에 **흰색 테두리**가 표시됨
5. 타임라인 위의 눈금을 클릭하거나, 메모를 **Ctrl+클릭**하면 해당 시점부터 재생

### 단축키

| 키 | 기능 |
|---|---|
| Ctrl+N | 새 메모 |
| Ctrl+F | 메모 검색 |
| Ctrl+R | 녹음 시작/중지 |
| Ctrl+S | 즉시 저장 |
| Ctrl+L | 잠그기 |

## 데이터 저장 위치

- Windows: `%APPDATA%\SecureMemo\vaults\<메모 공간>\`
  - `vault.json`: 키 확인용 정보(솔트, 반복 횟수) — 비밀번호나 키는 저장하지 않음
  - `memos\*.enc`: 암호화된 메모
  - `audio\*.sma`: 암호화된 녹음

## 보안

- 비밀번호에서 PBKDF2-SHA256(200,000회, 무작위 솔트)으로 키를 유도
- 메모와 녹음은 AES-256-GCM으로 암호화 (변조 감지 포함)
- 녹음은 녹음하는 동안 바로 암호화되어 평문 음성이 디스크에 남지 않음
- 이전 버전 데이터는 해당 비밀번호로 처음 열 때 자동으로 새 방식으로 다시 암호화됨
- 온라인 전송 없음 (업데이트 확인 제외)
